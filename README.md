# 🚆 RailBite

An on-seat food ordering web application designed for railway passengers. RailBite allows users to order food directly to their seat during train journeys, while vendors and admins manage orders seamlessly.

---

## ✨ Features

### 👤 Customer
* Browse available food items
* Place orders directly to seat
* Track order status

### 🏪 Vendor
* Manage food menu
* Accept / reject orders
* Update order status

### 🛠️ Admin
* Manage users (Customers & Vendors)
* Monitor orders
* Platform-level control

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/developer-uday/railbite.git
cd railbite
```

### 2. Setup Backend

```bash
cd server
npm install
npm run dev
```

### 3. Setup Frontend

```bash
cd client
npm install
npm run dev
```
